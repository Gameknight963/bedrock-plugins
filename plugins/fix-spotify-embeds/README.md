# Fix Spotify Embeds

Sets Spotify embed previews to the volume selected in Settings. The default is 10%. Changing the setting updates open Spotify players.

Disabling restores the audio hooks and volumes changed by the plugin. It does not affect the Spotify desktop app or other people in a shared activity.
