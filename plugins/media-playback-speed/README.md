# Media Playback Speed

Adds a compact speed selector to audio and video attachments in chat. Choose separate default speeds for voice messages, other audio and videos in Settings.

Controls apply to media in the currently loaded messages, not YouTube/Spotify iframe players or voice calls. Changing a default updates the loaded media of that type.

Adapted from [MediaPlaybackSpeed](https://github.com/Equicord/Equicord/tree/e0e85c8d4f6dc73aac9368cf3f4b2200eac4d4b4/src/equicordplugins/mediaPlaybackSpeed), by D3SOX. Licensed under GPL-3.0-or-later; see LICENSE and NOTICE.
