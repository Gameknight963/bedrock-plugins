# YouTube Adblock

Blocks ads in YouTube embeds and the Watch Together activity. It removes ad metadata from player responses, hides advertising elements, and skips video ads when possible.

The effect is local: other people in Watch Together may still see ads. YouTube changes can affect how well blocking works.

Enabling applies to open embeds and new ones. Disabling removes the script hooks and styles. Reload an embed if its player still reflects changes made while the plugin was enabled.

Based on [Vencord/Equicord's YoutubeAdblock](https://github.com/Equicord/Equicord/tree/e0e85c8d4f6dc73aac9368cf3f4b2200eac4d4b4/src/plugins/youtubeAdblock.desktop), by ImLvna, Vendicated and contributors, using AdGuard's [Block YouTube Ads](https://github.com/AdguardTeam/BlockYouTubeAdsShortcut).
