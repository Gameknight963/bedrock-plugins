# ViewRaw

The message toolbar has a **View Raw** button. Left-click opens the message content and JSON data; right-click copies the raw message content. You can swap those actions in settings.

**View Raw** also appears in server, channel, user, role and profile context menus. The message context-menu entry is optional.

Dialogs have buttons to copy the JSON and message content. Keys are sorted alphabetically by default, and **Strip Sensitive Data** removes email addresses, phone numbers and other personal fields from the displayed and copied JSON.
