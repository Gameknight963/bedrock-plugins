# Theme Attributes

Adds `data-tab-id` to settings tabs and `data-author-id`, `data-author-username` and `data-is-self` to messages.

Avatar images expose `--avatar-url-128`, `--avatar-url-256`, `--avatar-url-512`, `--avatar-url-1024`, `--avatar-url-2048` and `--avatar-url-4096`. Themes can use these variables to display larger avatars.

For example, `[data-is-self="true"]` selects your messages.
