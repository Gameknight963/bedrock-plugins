# Translate

Use **Translate** in a message's hover toolbar or right-click menu. The translation appears below the message, with its source language and a **Dismiss** button.

The translate button beside the chat input opens the language dialog. Choose source and destination languages for received messages and messages you send. Shift-click or right-click the button to toggle **Auto Translate**.

Google Translate works without configuration. DeepL requires a Free or Pro API key; Kagi requires a session token. Text you translate is sent to the selected provider.
