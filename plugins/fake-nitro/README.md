# FakeNitro

Send custom emoji and stickers from other servers as links. FakeNitro displays those links as emoji and stickers locally; other people see links or previews unless they use a compatible plugin. Animated PNG stickers are converted to GIF attachments.

Settings control emoji and sticker sizes, link text, and whether to render expressions inside longer messages. If a channel does not allow embeds, a confirmation explains how the link will appear before you send it.

Also enables client themes, app icons and higher streaming quality options. These are client-side changes, not a Nitro subscription.
